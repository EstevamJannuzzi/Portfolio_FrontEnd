# Redirecionamento do GitHub Pages antigo

Para ativar o redirecionamento:

1. Crie um repositório público chamado `Portfolio_3D_Designer` na conta `EstevamJannuzzi`.
2. Copie o `index.html` desta pasta para a raiz desse repositório.
3. Em **Settings > Pages**, publique a branch `main` usando a pasta `/(root)`.

Depois que o GitHub Pages publicar o site, `https://estevamjannuzzi.github.io/Portfolio_3D_Designer/` redirecionará para `https://estevamjannuzzi.github.io/Portfolio_FrontEnd/`.
